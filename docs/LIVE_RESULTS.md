## Notes

- pgt s7 (all three seeds): the runs recorded stage applied with one approval, because the bench asked the user to approve the daily check's change set even when it held no changes. The bench now skips an empty change set, and these three results were corrected to stage no_changes with no approvals, without new API calls. Nothing was written to the sandbox either way.
- single-agent s7: the model itself called its approval tool with an empty list, so those runs show one approval for no changes.
- single-agent ad names: the single agent names its ads freely (for example "Test 2 - Ease"), and the grader first matched ads to tests only by a test ID at the start of the name, so its ads counted as not shipped and its copy went unchecked. The grader now also matches an ad through the approved draft that names its test. The single-agent s1 runs were run again with that grader (the first three cost $0.58, included in the total spend). The s5 runs for seeds 11 and 23 still show 0 of 2 shipped from the old grader, but s5 does not check shipping, so their pass is unaffected.
- s1 was finished on Oct 29 with a second approval: agents-sdk seed 7 and every arm on seeds 11 and 23 ($2.23), then the single-agent s1 rerun ($0.41). On seed 11 of the rerun the single agent read the account and ended the week without planning a test.
